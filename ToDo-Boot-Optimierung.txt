STATUS: UMGESETZT (2026-09-30)

Ist-Zustand (src/mp3.cpp, init()):
- Der Retry-Loop ruft getTotalTrackCount() in der Bedingung auf
  (while ... getTotalTrackCount() == 0).
- Direkt danach wird getTotalTrackCount() fuer das Log erneut aufgerufen.
- Ausserdem ist unklar, ob der zweite Wert ueberhaupt gebraucht wird.

Schritte:
- [x] 2.1 Wert einmal ermitteln und in einer lokalen Variablen halten
          (z. B. uint16_t trackCount = 0;).
- [x] 2.2 Retry-Loop so umbauen, dass die Variable verwendet wird statt
          eines erneuten Aufrufs pro Schleifendurchlauf.
- [x] 2.3 Log-Ausgabe auf die bereits ermittelte Variable umstellen
          (kein zweiter Aufruf).
- [x] 2.4 Verhalten bei dauerhaftem 0-Wert unveraendert lassen
          (Timeout bleibt; keine Endlosschleife).
- [x] 2.5 Sicherstellen: Semantik "einmal ermitteln, einmal loggen" aendert
          die uebrige Logik nicht.

Erwartetes Ergebnis: getTotalTrackCount() wird pro init() hoechstens einmal
pro tatsaechlich noetigem Abfragezeitpunkt aufgerufen, nicht mehr doppelt.
